# MacMess

Versions publiées de MacMess (anciennement Voisin), une messagerie chiffrée entre Mac proches, sans serveur.

[Télécharger la dernière version](https://github.com/erdemm1020/voisin-updates/releases/latest/download/MacMess.dmg)

Ce dépôt contient uniquement les versions compilées. Une fois installée, l'app se met à jour toute seule.
